COASTAL PROTECTION ETHICS SIMULATOR

HOW TO RUN (NO INSTALLATION REQUIRED)
1. Extract the ZIP file.
2. Open the coastal_ethics_project folder.
3. Double-click index.html.
4. The project opens in Chrome, Edge, or another browser.
5. Select Wave Intensity (Low / Medium / High).
6. Select Protection Method (No Protection / Seawall / Breakwater / Mangrove).
7. Click Run Simulation.
8. Watch the waves and read the results and ethics section.

TECHNOLOGY: HTML + CSS + JavaScript (all in index.html)
PROJECT TYPE: First-year educational software demo, offline.

MODULES:
1. User input
2. Animated coastal scene
3. Protection method comparison
4. Illustrative result calculation
5. Environmental ethics and legal awareness

IMPORTANT: The scores are invented for demonstration and are not scientifically validated. Do not use them for actual engineering or legal decisions.
